# Flujo de trabajo

## Ciclo de desarrollo en LogiGho

1. Se define la funcionalidad a desarrollar
2. Se desarrolla el código
3. **Se documenta en este repo** ← paso obligatorio
4. Se hace commit del código + la documentación
5. Se hace PR / merge

## Convenciones de commits

```
feat: descripción de la nueva funcionalidad
fix: descripción del bug corregido
docs: actualización de documentación
refactor: refactorización sin cambio de comportamiento
```
