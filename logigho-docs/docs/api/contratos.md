```
https://[api-gateway-url]/api/v1
```

## Endpoints documentados

> Completar a medida que se documente cada endpoint.

### Ejemplo de formato

#### `POST /recurso`

**Descripción:** Qué hace este endpoint.

**Body:**
```json
{
  "campo": "tipo"
}
```

**Respuesta exitosa (200):**
```json
{
  "id": "string",
  "resultado": "..."
}
```

**Errores posibles:**

| Código | Descripción |
|---|---|
| 400 | Datos inválidos |
| 401 | No autorizado |
| 500 | Error interno |
